# v0.7.2 - 2026-09-28

- **バグ修正（指示書違反）**：`color_model=fme`の組込み設定プリセット9個中7個
  （`config.standard.json`等）が、FMEマニュアル公式値(±0.1)ではなく
  暫定値(±0.03)を`curvature_limit`として使っていた。プロジェクトの方針
  （±0.03 は FME 標準値として上書きしない）に反していたため、
  該当7プリセットをFMEマニュアル公式値(0.1)へ修正し、暫定値(0.03)は新規
  `config.forestry_tuned.json`として明確に分離した。
- **バグ修正**：`read_config`の裸のデフォルト値が、`color_model`未指定（＝legacy扱い）
  でも`curvature_limit=0.03`（暫定値）のままだった。QGISプラグイン版と同種の不具合
  （2026-09-24付QGIS版CHANGELOG参照）がこのCLI版には未反映だったため、裸のデフォルトを
  `0.05`（独自方式=independent_v040相当の値）へ修正し、`color_model=fme`かつ
  `curvature_limit`省略時のみFMEマニュアル値`0.1`を採用するロジックを追加した。
- **機能追加**：RGBストレッチを`none`／`nagano_reference`／`custom`から選択可能にする
  `stretch_mode`／`stretch_range`を追加（指示書4.3節）。従来は常に長野県実績値
  ストレッチが強制適用されており、選択肢がなかった。全FMEプリセットへ明示的に
  `"stretch_mode": "nagano_reference"`を追加（従来の発色を維持）。
- `run.json`に`rendering`ブロックを追加し、使用した方式ID・正規化範囲・全LUT色
  （傾斜A/B・曲率A等の非公開定数を含む）・5レイヤー重み・ストレッチ設定・曲率符号を
  記録するようにした（指示書7章）。
- 回帰テスト追加：`ConfigDefaultsTests`（裸のデフォルト値、プロファイル分離）、
  `StretchModeTests`（3方式の選択・不正値の拒否・レンダリング結果への反映）。

# v0.7.1 - 2026-09-19

- FMEマニュアル／Forestgeoチューニングを参考にした5レイヤー合成とRGB別ストレッチを追加。
